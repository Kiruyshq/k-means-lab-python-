# K-means на Python

Лабораторная работа №1, вариант А2. Программа генерирует двумерные данные,
разбивает их на кластеры методом k-средних и строит графики.
Ядро алгоритма реализовано на списках без NumPy и готовых моделей sklearn.

## Установка

Нужны Python 3.11+ и [uv](https://docs.astral.sh/uv/).
Откройте терминал в папке проекта и установите зависимости:

```bash
uv sync --extra dev
```

## Запуск

```bash
uv run python -m kmeans --samples 300 --k 3 --iter 100 --seed 42
```

Программа печатает число итераций, размеры кластеров и **inertia** — сумму
квадратов расстояний от точек до их центров. Для этого примера результат:

```text
Iterations: 2
Cluster 0: 100 points
Cluster 1: 100 points
Cluster 2: 100 points
Inertia: 597.64
```

| Параметр | Назначение | По умолчанию |
|---|---|---|
| `--samples` | Количество точек | `300` |
| `--k` | Количество кластеров | `3` |
| `--iter` | Максимум итераций обычного обучения | `100` |
| `--seed` | Воспроизводимость данных и начальных центров | `42` |
| `--spread` | Разброс точек вокруг исходных центров | `1.0` |

## Графики

```bash
uv run python -m kmeans --plot
uv run python -m kmeans --elbow --k-max 10
```

- `--plot` сохраняет точки и центры в `clusters.png`.
- `--elbow` сохраняет график inertia для разных k в `elbow.png`.
  На стандартных данных выраженный локоть находится при k=3.

Файлы создаются в текущей папке и перезаписываются при повторном запуске.
В режиме локтя `--k`, `--iter` и `--plot` не используются.

## Структура

```text
kmeans/
  model.py       # KMeans, k-means++ и расчёт локтя
  data.py        # генерация данных
  plots.py       # сохранение графиков
  cli.py         # аргументы и сценарии запуска
  __main__.py    # запуск python -m kmeans
tests/           # проверки алгоритма
```

Алгоритм чередует назначение точек ближайшим центрам и пересчёт средних.
Пустой кластер сохраняет прежний центр. Остановка происходит по сдвигу
центров или лимиту итераций. k-means++ улучшает инициализацию, но не гарантирует
глобальный минимум; для совпадающих точек возможны пустые кластеры.
